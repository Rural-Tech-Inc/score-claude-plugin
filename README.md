# S.C.O.R.E. plugin for Claude

The official [S.C.O.R.E.](https://score.ruraltechnologies.co) plugin for Claude, by RURAL Technologies. It connects Claude to your S.C.O.R.E. point of sale and inventory account: see your stores, ask about sales, stock and products, and create a store, all in plain words.

## Install in Claude Code

```
/plugin marketplace add Rural-Tech-Inc/score-claude-plugin
/plugin install score@rural
```

Then run `/mcp`, choose **score** and sign in.

## In claude.ai or the Claude apps

Add a custom connector with the address `https://api-prod.ruraltechnologies.co/mcp` and sign in when asked.

See [plugins/score/README.md](plugins/score/README.md) for what you can ask and how to end Claude's access.
